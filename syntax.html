6.9 文🔗

Originates from syntax object.

文
ideograph

  connotation : syntax
  originates from : 文
  originally means : tatoo, text, texture, script
卩
ideograph

  connotation : identifier
  originates from : 卩
  originally means : identifier, token, certificate
Also can be seen as the short for 节.

Examples:
> (文? #'(+ 1 2))

#t

> (文? #'(+ 1 2))

#t

> (文? #'1)

#t

> (卩? #'1)

#f

6.9.1 􏵥 􏵢 􏵡 􏵣 􏵤🔗

source location is especially called 􏵟, which has fields we call: 􏵥, 􏵡, 􏵢, 􏵣, 􏵤.

􏵟 : 文 + 元
ideograph

  connotation : source location of syntax
􏵥 : 文 + 止
ideograph

  connotation : path of source location
􏵢 : 文 + 韦
ideograph

  connotation : line of source location
􏵡 : 文 + 𢀖
ideograph

  connotation : column of source location
􏵤 : 文 + 占
ideograph

  connotation : span of source location
元
ideograph

  connotation : source location
  originates from : 元
  originally means : head, begining, original
止
ideograph

  connotation : location, path
  originates from : 止
  originally means : foot, footprint
Also can be seen as the short for 址, which exactly means address, location.
𢀖
ideograph

  connotation : column
  originates from : 𢀖
  originally means : the vertical line in the loom
Also can be seen as the short for 经.
韦
ideograph

  connotation : line
  originates from : 韦
  originally means : the horizontal line in the loom
Also can be seen as the short for 纬.
立
ideograph

  connotation : position
  originates from : 立
  originally means : positon, location
Also can be seen as the short for 位, which exactly means position.
占
ideograph

  connotation : span
  originates from : 占
  originally means : occupy

Examples:
> (􏵥 #'a)

'eval

> (􏵡 #'a)

0

> (􏵢 #'a)

3

4

6.9.2 刘 文化􏿴 文化云 云化文🔗

云
ideograph

  connotation : data
  originates from : 云
  originally means : cloud
刘 : 文 + 刂
ideograph

  connotation : unwrap syntax
  originates from : 刘
  originally means : a kind of weapon, kill
刂 especially means unwrap here when it comes to 文 as component in the character.

Examples:
> (刘 #'a)

'a

> (刘 #'(a b c))

'(#<syntax:eval:2:0 a> #<syntax:eval:2:0 b> #<syntax:eval:2:0 c>)

> (文化􏿴 #'(a b c))

'(#<syntax:eval:3:0 a> #<syntax:eval:3:0 b> #<syntax:eval:3:0 c>)

> (文化云 #'(a b c))

'(a b c)

> (云化文 #f '(a b c))

#<syntax (a b c)>

6.9.3 基础例程🔗

 (require ming/racket/base) package: ming

transformer

transformer

transformer

卩? : 卩 + ?SFX = identifier?

transformer

􏵥 : 􏵥 = syntax-source

transformer

􏵢 : 􏵢 = syntax-line

transformer

􏵡 : 􏵡 = syntax-column

transformer

􏵣 : 􏵣 = syntax-position

transformer

􏵤 : 􏵤 = syntax-span

transformer

刘 : 刘 = syntax-e

transformer

文化􏿴 : 文 + 化 + 􏿴 = syntax->list

transformer

transformer
