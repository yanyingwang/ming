4 General Ideographs🔗

亻 
ideographs

  connotation : general derived set
  originates from : 亻
  originally means : person, people, human
As component of ideographs, it specifies The type of output data is same as the input. And the elements of output data are part of the input. In particular, 化 is exceptionally different, which has a more diverse usages scenarios, 化IFX, 化SFX. Note that, if the procedure name has another ideograph prefixed as a word, the input and output type is determinated by the prefixed ideographs, e.g.,  􏻿𢪛 􏿰攸 􏻿弔 􏿰弔 􏻿巨 􏿰巨.
Examples:  伄 攸 𰂋 偏 􏾜 􏾛 偅 𠆯 􏹈

🐘 弓* is similar to 弓 except the process is strengthened.

ideograph

  connotation : strengthen
Almost has the same usage as the one named without *, except this strengthen the processing of inputted data. Thus the data of output may become longer, and the type may be changed accordingly.

🐘 􏹊~ is similar to 􏹊 except the process is softened.

  connotation : ~ as suffix, implies strengthen

Examples:  􏹊~
